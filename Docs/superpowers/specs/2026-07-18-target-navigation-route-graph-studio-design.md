# 目标导航可靠性与路网工作室设计

日期：2026-07-18

## 目标与交付顺序

本设计修复目标导航分支的四个合并阻断项：同步 integrated develop、按统一预计耗时选择传送起点、以部分规划和局部导航替代可恢复的 `NoRoute`、将规划与主界面执行准备解耦。导航核心在 `codex/target-navigation-p0-p8` 交付；路网补丁层和工作室从其上建立堆叠分支 `codex/route-graph-studio`。

## 导航规划

`RouteNavigationPlan` 增加 `Complete`、`PartialToFrontier`、`LocalOnly`、`HardFailure` 四种完成模式，并保存路网任务、局部接管目标、前沿节点、实际选中的传送点和成本明细。图损坏、目标缺失和完全没有有效位置属于硬失败；路网不连通和目标离路网较远不再直接返回 `NoRoute`。

所有候选统一使用预计耗时秒数。新增 `RouteNavigationCostOptions`，默认值仅作为可配置初值：Walk 4.5、Run 6、Dash 7.5、Swim 3、Fly 6、Climb 2、Jump 4 游戏单位/秒；传送 18 秒；传送最小收益 8 秒；局部直达上限 80 游戏单位；漂移重规划阈值 20 游戏单位。成本明细必须标明每一项来自遥测还是估算，便于实机校准。

遥测样本充足时优先使用真实平均耗时，其他边按游戏坐标距离和移动模式速度估时。审核状态、健康度、未知连接和合成反向边只在秒制成本上增加惩罚；Disabled 和 Rejected 边不可搜索。

当前位置与所有可用传送点分别求最优计划。对已经求出的有序路线逐点检查传送接入：路线点距离传送图标或实际出生点不超过 10 时视为可接入；存在多个时必须选路线顺序中最后一个，并裁掉该点之前的全部路线。一次完整导航仍最多实际执行一次传送。界面高亮实际选中的传送点，并显示名称、预计总耗时和预计步行距离。

导航收敛为两种主要方式：`传送点 → 局部导航 → 目标`，以及 `传送点 → 路网 → 局部导航 → 目标`。当前位置只有在目标处于 80 游戏单位安全范围内时才可直接局部导航。当前位置到最近路网节点或边的游戏距离超过 80 时，禁止远距离直走，改选距目标最近的可用传送点，从真实出生位置开始局部导航；没有传送候选时明确失败。

完整连通时任务到达精确目标。不连通时选择可达且最接近目标、风险和耗时合理的前沿节点；部分任务只到前沿，不附加目标动作或虚假的精确目标路点。

## 局部导航

新增可等待的多图标局部跟随器，参考 `H:\Auto\BadGI-JsScript\自动剧情加载器\main.js` 的多模板追踪循环，并修正其连续失败计数等边界。模板按任务语义优先，支持 Bigmap、Into、Start、Finish、Enter、Question、Task 等组；同组可包含多张模板，识别区域、阈值、对准区间、步进时间和失败次数均配置化。

局部接管优先尝试任务图标组。跟随器通过取消令牌返回 Completed、IconUnavailable、TimedOut、EnteredTalk、Cancelled 或 Failed，不自行占用 TaskRunner。只有图标无法识别且目标在配置的安全距离内时，才使用实时坐标直达，并复用 PathExecutor 的定位、卡死检测和 TrapEscaper。

局部导航结束后返回明确结果；坐标直达始终受 80 游戏单位安全上限约束，超距且无图标时安全失败，不把当前位置远距离直走作为兜底。

## 规划与执行准备

规划运行时只读取带地图和时间戳的最后有效坐标，不启动截图器、不激活窗口，也不要求主界面。执行运行时负责启动截图、检查 TaskRunner、激活游戏、等待可执行界面、重新定位和执行任务。

主界面直接执行；背包、大地图等可关闭界面使用 `ReturnMainUiTask`；剧情对话交给 AutoSkip 并最多等待十分钟；加载画面最多等待两分钟；未知界面三十秒后安全暂停。返回主界面后的实时坐标超过漂移阈值时自动重规划。

工作流增加缓存坐标规划、等待主界面、重新规划、执行路网段、执行局部段和部分完成状态。TaskRunner 独占、窗口前台监控和所有结束路径释放键鼠输入保持为硬约束。

## 生成图、人工补丁和工作室

基础图升级为 schema v3，写入 `route_navigation_graph.generated.json`。运行时按生成图、内置贡献补丁、用户补丁、健康度快照的顺序组合内存图；旧 `route_navigation_graph.json` 仅兼容读取。

来源信息规范化保存仓库、相对路径、路线名、作者、来源类型和出现次数。节点增加层级、楼层、环境、高度范围和区域标签；边增加人工审核状态、自动健康状态、游戏距离、预计秒数、完整折线和合成反向标记。

同地图且同已知层允许六像素吸附，未知层默认两像素。未审核 Walk、Run、Dash、Swim 合成反向边保留但标为高风险；攀爬、飞行、跳跃和特殊动作保持单向。

补丁包含唯一 ID、基础图 ID、作者、原因、时间和操作列表，并按补丁文件名、补丁 ID 确定顺序。每个补丁整包验证；基础图或目标失配时隔离整个补丁，其余补丁继续。禁止容差自动重绑。边可使用 Disabled 或 Rejected 保留来源，也可显式删除人工连接；删除节点时同时删除其连接。

独立 `RouteGraphStudioWindow/ViewModel` 采用三栏工作台：左侧过滤和对象树，中间地图与图拓扑，右侧属性、来源和审核，底部显示 QA、补丁预览和操作历史。使用空间索引、视口查询和 LOD，禁止为全量节点和边创建 WPF 图元。

QA 覆盖结构、连通分量、重复、自环、异常长度、层级冲突、疑似错误吸附、反向边、成本、来源和传送入口。缺少高程或地形语义时只输出疑似或数据不足，不自动禁边。
